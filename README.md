# 旋转飞刀

[打开手机试玩](https://cxcboss.github.io/spinning-knife/)

新存档从第一关、初始小刀和零金币开始。通关获得金币，装备库可免费试刀，购买后才能带入关卡。首次失败可点广告复活一次，回到附近柱子。公开试玩不接商业广告，其他广告位仅展示。签到和金币购买照常生效。

## 试玩统计

首次开局可以选择分享匿名数据或仅试玩，之后可以在设置中更改。每局使用独立随机编号。记录关卡、最后落稳的柱子、失败原因、复活、通关、收益、装备、补给操作和前台帧间隔。试玩统计按设备大类区分，无跨局玩家标识。

数据存入独立的 Cloudflare Worker，按开局或操作日期保留 30 天。客户端每 15 秒及状态变化时更新，短时离线后会重试，同一局按最新版本计一次。打开游戏但未选择统计、首页演示和后台停留均不产生游玩时长。

维护者可打开部署电脑上的 `.private/试玩数据.html` 查看最近 1、7 或 30 天的数据，按设备筛选。回归测试和真机验收使用 `?qa=1`，与正式样本独立。报表口令不进入仓库。私人报表中的优先复查项来自有足够样本的关卡、设备和物品。

## 发布

推送到 main 会先运行 `node --test tests/*.test.cjs`，再发布 GitHub Pages。统计服务的入口和报表在 stats 目录，用已授权的 Wrangler 部署。首次部署需要设置随机 REPORT_KEY 密钥，后续部署保留已有密钥。
