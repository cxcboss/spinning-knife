# 旋转飞刀

[打开手机试玩](https://cxcboss.github.io/spinning-knife/)

新存档从第一关、初始小刀和零金币开始。普通关通关收入是沿途金币加上终点奖励（2 金币 × 命中倍率）。装备库可免费试刀。失败后，模拟广告和库存复活药水每局各可用一次，按任意顺序使用都会回到附近的柱子。补给站可买药水，七日签到末日也有一瓶。其他广告位供预览。

## 无尽挑战

从首页进入。每天按本机日期有 3 次开局。每次完成系统分享增加 2 局，每天最多领 3 次分享奖励。复活不扣次数。地形和道具每局重新随机，挑战没有终点。失败后可选复活，或结算本局全部金币。失败时关闭页面，重新打开后会补结算已记录的收益。

网页通过系统分享完成回执发放次数。缺少系统分享能力的浏览器可复制公网游戏链接，次数由分享回执发放。微信小游戏接入点为 `endlessSharePlatform`，分享完成后返回 `{ day, id }`，每个凭据仅计一次。

## 成就、每日挑战与转盘

成就记录普通关、无尽和每日挑战的实际战绩。领奖可获得金币或限定刀具，已领取的成就可以分享。装备库支持预览限定刀和试切。

每日挑战按本机日历日期生成。四种玩法分别考验切水果、准确落点、空中切割和限时抵达。玩家都使用初始小刀，每天可开局一次，失败得 35 金币，达标通关得 280 至 320 金币。重新打开页面会保留当天的使用记录。

幸运转盘每天首抽免费，此后每次 120 金币。奖池含金币、库存补给和两把限定刀具。每次抽奖的扣款和奖励写入同一份存档，重新打开页面可查看最近的奖品。

## 试玩统计

试玩默认开启匿名统计，点击开始即可进入关卡。设置中可随时关闭，之前已关闭的选择会保留。每局使用独立随机编号。记录关卡或无尽模式、最后落稳的柱子、失败原因、两种复活、结算金币、装备、补给操作和前台帧间隔。报表可按试玩版本查看，普通关表现和无尽挑战分别展示。试玩统计按设备大类区分，无跨局玩家标识。

数据存入独立的 Cloudflare Worker，按开局或操作日期保留 30 天。客户端每 15 秒及状态变化时更新，短时离线后会重试，同一局按最新版本计一次。报表也记录每日挑战开局与结算、领奖、转盘和战绩分享的次数。首页演示、关闭统计的试玩和后台停留均不计入游玩时长。

维护者可打开部署电脑上的 `.private/试玩数据.html` 查看最近 1、7 或 30 天的数据，按设备筛选。回归测试和真机验收使用 `?qa=1`，与正式样本独立。报表口令不进入仓库。私人报表中的优先复查项来自有足够样本的关卡、设备和物品。

## 发布

推送到 main 会先运行 `node --test tests/*.test.cjs`，再发布 GitHub Pages 试玩包。打包时注入试玩标记，直接打开源码页使用常规模式。试玩设置使用当前页面的临时存档，关闭所有试玩开关或刷新后恢复原本进度。开启开关期间的游戏记录不会进入试玩统计。

统计服务的入口和报表在 stats 目录，用已授权的 Wrangler 部署。首次部署需要设置随机 REPORT_KEY 密钥，后续部署保留已有密钥。
