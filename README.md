# 小刀飞飞飞

竖屏 3D 小游戏。点击让小刀起跳，在空中再点一下调整落点。用刀尖插稳柱子，切开沿途目标，在终点争取更高倍率。

[打开网页试玩](https://cxcboss.github.io/spinning-knife/)

**维护前请先阅读[《双端维护必读》](./必读.md)。自动玩仅供网页试玩，永久禁止加入微信小游戏。**

## 微信小游戏

在微信开发者工具以小游戏打开 `wechat/`，AppID 为 `wx3549cc0b0a3d781b`。项目直接使用微信的 WebGL 画布、触摸、音频、存储和分享接口。全屏场景铺满手机，操作区按右上角胶囊、屏幕安全区域和底部手势区排版。

渲染请求微信支持的 60 FPS，物理和碰撞使用每秒 120 步。自动画质按帧耗时调整 3D 分辨率。菜单和文字使用缓存纹理。界面暂停时冻结场景，切到后台后暂停游戏和声音。

`node scripts/build-wechat.cjs` 从独立网页同步公共渲染与玩法逻辑。`node scripts/build-wechat.cjs --check` 校验两端代码是否同步。`node --test tests/*.test.cjs` 运行核心回归。游戏所需图片和声音随包提供。修改程序化美术、刀具模型或合成配乐时，可用安装了 Playwright、Chrome 和 ffmpeg 的电脑运行 `node scripts/bake-wechat-assets.cjs` 重新生成资源。

## 玩法与进度

普通关从第一关、初始小刀和零金币开始。通关收入由沿途金币和终点奖金组成，每一倍率对应 2 金币。复活药水可从补给站或签到获取，每局可用一瓶。装备库支持预览和试切。

无尽挑战每天有 3 次基础开局。玩家可以发出好友切物挑战，让好友免费玩一局 45 秒的空中切物狂潮。好友完成后把成绩卡发回，邀请人当天在发起邀请的设备打开卡片即可获得 2 局，每天最多 3 份。重复打开同一份成绩只计一次。挑战卡只携带当日随机挑战码和回传分数，使用微信系统分享，无需读取好友名单。网页试玩支持同样的挑战链接。

空中切物狂潮每局 45 秒。普通关、无尽和每日挑战记录成就，奖励金币或限定刀具。每日挑战每天可开局一次。幸运转盘每天首抽免费，之后每次 120 金币。金币、装备和关卡进度保存在当前设备。

## 维护

流量主开通后，在 `wechat/rewards.js` 填入已获批准的对应单元 ID，即可恢复相应入口。未配置的位置不会创建视频实例或显示入口，完成播放才会发放对应奖励。

网页是可直接打开的 `小刀飞飞飞.html`。GitHub Pages 发布流程通过测试后生成公网试玩包。试玩设置使用临时进度，关闭开关或刷新后恢复原存档。
