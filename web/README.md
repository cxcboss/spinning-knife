# 网页试玩

[在线试玩](https://cxcboss.github.io/spinning-knife/) · 本地可直接打开 [index.html](index.html)。

- `index.html`：单文件入口，包含公共游戏引擎和网页界面。关卡、物理、刀具等公共更新由微信和 B站构建复用。
- `icon.png`：Pages 站点图标。`tests/`：网页碰撞、进度、无尽、空中狂潮及自动玩回归。
- `archive/`：忽略提交的旧试玩资料、测试记录或临时产物。

试玩版保留挑战链接、自动玩和隐藏试玩设置，不接广告。设置中的自动玩可选「正式模式」或「空中狂潮」：正式模式逐关结算，第 60 关后回第 1 关；空中狂潮结算后开新局。返回主页可结束。隐藏设置只在 Pages 的试玩包启用，本地原始文件默认不启用；打开隐藏试用不会改写正常存档。

空中狂潮前三局每 20 分得 1 金币；之后仍可直接开局，每 50 分得 1 金币，额外局每局最多 15、每天共最多 40 金币。每局可直接加 15 秒一次；无尽保留 3 次基础开局与网页已有的好友挑战加局，不移入微信广告加局。

GitHub 的 Pages 工作流仅发本目录的 HTML 和图标。它启用试玩标记，不上传微信或 B站资料。
